| `ext/local` | the free defaults of `ext`'s interfaces, each doing what Conductor does without a provider, named `local` and safe for concurrent use: `Identity` (recognises no token), `Router` (the empty route; keeps nothing it is told), `Continuity` (keeps nothing; `Restore` answers `ErrNothingToRestore`), `AllowAll` (every feature allowed, no limit; no code of this repository asks it) `Media` (no ICE server beside the configured ones, no room) and `Native()`, the native Runtime (`pty.Start` behind two checks of the context, with exactly the spec's environment, the process held unreaped until the call returns (`pty.StartHeld`) so that a panic kills its group (`Abort`), `proc.Run` and `proc.Serve` with the environment whole, `proc.Probe`, `proc.FreePort`; `where` `native`, every run taken); the lists need no default. `Fill` puts a default in every empty slot of what `ext.Freeze` answers: the one place any code asks whether a provider is registered. `boundary_test.go` fails a process started or signalled outside the runners, or a runner used past the Runtime. May import the standard library, `ext`, and `internal/pty` and `internal/proc` (the runners the native Runtime is made of, which import nothing of `ext`), nothing else |
| `ext/exttest` | the fakes and the contract suite another module runs in its CI (`docs/plans/ext.md`, C9): a fake per interface and for `ext.Host`, each safe for concurrent use, each that records with `Changed` (`Await`); the `Network` a provider under test reaches its service through, which records every dial and request with its context, refuses one under the context of one of the suite's calls and, blocked, holds every one, and every byte of a connection it dialled, on a gate; one check function per interface (`Identity`, `Router`, `Context`, `Sink`, `Continuity`, `Entitlements`, `Media`, `Runtime`, `Starter`) and `RunAll` over an `ext.Providers`, its checks by kind in one table (`byKind`) that a new interface joins with a row. Article 8 is checked by the network, never a clock: a call must neither dial on its own path nor wait on the shut gate past the wait the server's guard gives it; `Restore` alone may stream from its service, and must end with its context. The Runtime's are in two parts (`docs/plans/runtime.md`, PR-5): `Runtime` starts nothing (`Name` and `Where` constant, `Takes` within `ext.TakesWait` from 32 goroutines at once), and `RuntimeExec` starts the helper a `RuntimeCase` names through the Runtime (`RunHelper`, the program's modes, run by a test binary's `TestMain` given `HelperArg`) and holds it to the contract: a terminal's directory, environment, input, resize, exit and stops, its context's two answers; `Run`'s argv, bounds, `Started`, timeout and cancel; a `Started` that panics; `Serve`, `Port` and one `Probe`. `RunAll` runs it with `WithRuntimeCase`'s case and fails a Runtime that is not the native one given none. `FakeRuntime` passes what is not scripted to a base (`SetBase`); `FakeTerminal` is a terminal over pipes. Imports the standard library, `ext` and `ext/local` only |

## Adding things

- **A provider**: implement an `ext` interface in another module (this
  repository holds none), register it in its package's `init` with the
  matching `ext.Register…` and do nothing else there, and build a `main`
  that blank-imports that package and calls `app.Main`. Start from `ext`'s
  package documentation: how a provider registers, starts and answers (from
  what it holds, never with a round trip on the call's path), and the
  guard's waits and bounds. No flag, key, environment variable or build tag
  turns one on. Its repository's CI runs `ext/exttest`'s contract suite
  against it (`RunAll`), with its service reachable and unreachable.
- **An agent**: add a catalog entry in config (or `internal/catalog/defaults.go`
  for built-ins) with `id`, `name`, `command` and `allowArgs`.
- **An API route**: handler in `internal/api`, auth via `requireAdmin` or
  `authenticate`, a test in `internal/api` (`api_test.go` or the route family's
  `*_test.go`), and the client call in `web/app/composables/useSessions.ts`.
- **A control message**: struct in `internal/proto/control.go`, dispatch in
  `ws_viewer.go` and `hostagent/peer.go`, TypeScript type in `protocol.ts`,
  handling in `transport/base.ts`, and a row in `docs/protocol.md`.
